# BatchStack

BatchStack is a lightweight desktop application for sequentially grouping and stacking FITS images in batch. It is designed for astronomy and astrophotography workflows where consecutive frames need to be combined, such as occultation timing, lucky imaging, or time-lapse master frame creation.

Example: given 12 images and a group size of 3, BatchStack groups them as `1-2-3`, `4-5-6`, `7-8-9`, and `10-11-12`, then writes one stacked FITS file for each group.


## Features

- PySide6 desktop GUI with a compact astronomy workflow.
- Five stacking methods: Average, Maximum, Median, K-Sigma (Regular), and K-Sigma (Median).
- Folder-based input and output selection.
- Configurable group size for consecutive-frame stacking.
- Live progress bar and timestamped activity log.
- Sorting by filename or FITS `DATE-OBS` header.
- Sequential or range-based output naming with a custom prefix.
- Optional inclusion of incomplete final groups.
- FITS handling for `.fits`, `.fit`, and `.fts` files.
- Supports `BZERO` / `BSCALE` rescaled FITS data by reading with memory mapping disabled.
- Preserves source headers and adds stack metadata.
- Cancellable background stacking via `QThread`.
- Help button opens `https://google.com`.
- Yellow-orange star-style window icon generated by the GUI.

```bash
git clone https://github.com/SahilPurabiya/BatchStack.git
cd BatchStack
pip install -r requirements.txt
```

## Usage

```bash
python main.py
```

### Quick Start

1. Select an input folder containing FITS files.
2. Select an output folder.
3. Choose group size, stacking method, sorting, naming, and data type.
4. Click Start.
5. Watch progress and messages in the log box.

## Settings

| Setting | Default | Description |
|---------|---------|-------------|
| Group Size | 3 | Number of consecutive frames per stack |
| Method | Average | Stacking combination method |
| Sort By | Filename | File ordering before grouping |
| Data Type | float32 | Internal processing precision |
| Naming Style | Sequential | Output filename style |
| Prefix | `stack` | Output filename prefix |
| Include Incomplete | Off | Whether to stack the final partial group |
| Iter | 5 | K-Sigma iteration count, shown only for K-Sigma methods |
| Kappa | 2.00 | K-Sigma rejection threshold, shown only for K-Sigma methods |

## Stacking Methods

| Method | Best For | Description |
|--------|----------|-------------|
| Average | General purpose | Arithmetic mean of all frames |
| Maximum | Bright-feature retention | Keeps the brightest pixel value in each pixel position |
| Median | Artifact rejection | Uses the median value in each pixel position |
| K-Sigma (Regular) | Average with outlier rejection | Iteratively clips outliers using mean/std, then averages remaining values |
| K-Sigma (Median) | Robust outlier rejection | Iteratively clips outliers using median/std, then takes the median |

### K-Sigma Parameters

K-Sigma methods expose two extra controls:

- `Iter`: maximum clipping iterations. Default: `5`.
- `Kappa`: rejection threshold in standard deviations. Default: `2.00`.

Lower Kappa values reject more aggressively. Higher values preserve more data.

## How It Works

```text
Input: 12 FITS files, Group Size = 3

Files sorted: img_001, img_002, img_003, img_004, ..., img_012

Group 1: img_001 + img_002 + img_003  ->  stack_0001.fits
Group 2: img_004 + img_005 + img_006  ->  stack_0002.fits
Group 3: img_007 + img_008 + img_009  ->  stack_0003.fits
Group 4: img_010 + img_011 + img_012  ->  stack_0004.fits
```

### Architecture

```text
BatchStack/
|-- main.py          # Entry point
|-- gui.py           # PySide6 interface
|-- stacker.py       # Background stacking engine
|-- test_stack.py    # Basic verification script
|-- requirements.txt # Python dependencies
|-- assets/          # Images and screenshots
```

`stacker.py` runs in a `QThread` so the GUI remains responsive. Each group is processed independently, so memory use is limited to the active group.

## Supported FITS Formats

- Extensions: `.fits`, `.fit`, `.fts` in upper or lower case.
- Primary HDU or first image extension with 2-D image data.
- 8-bit, 16-bit, 32-bit, and 64-bit integer or floating point image data.
- Files using `BZERO` / `BSCALE` header keywords.

All images in a group must be 2-D and have the same shape. Frames that do not match are skipped with a warning.

## Output FITS Headers

BatchStack preserves the original FITS header from the first readable frame in each group and adds:

| Keyword | Example Value | Description |
|---------|---------------|-------------|
| `STACKN` | `3` | Number of frames used in the stack |
| `STACKMT` | `Average` | Stacking method used |
| `STACKSW` | `BatchStack` | Stacking software identifier |
